# OpenSVN × Versions³ 功能差距清单

> 基准：Versions³ 3.0（2026-10-08；官网、Release Notes、Support FAQ）与 OpenSVN v0.1.0-dev
> （`apps/macos` 源码及测试，2026-10-20）。Windows 端当前为空，不参与对比。
>
> 图例：✅ 已具备　◐ 部分具备　❌ 未实现　— 官网未说明

## 结论

OpenSVN 已覆盖 Versions 的日常闭环——检出 → 修改 → 查看差异 → 提交 → 更新——并在冲突安全、
失败恢复、进程与凭据处理上更严格。差距集中在三块：

1. **浏览与检索**：仓库浏览器、单文件历史、blame、时间线搜索；
2. **高级 SVN**：文件锁、externals、远程 copy/tag；
3. **平台集成**：Finder 扩展、外部 diff 工具、通知、自动刷新、证书/代理 UI。

Versions 不是超集：它不做分支间 merge、不支持 Git；这两点 OpenSVN 也未实现（后者不在规划内）。

## 7. OpenSVN 已领先的部分

- **冲突处理**：逐块决策的合并编辑器；解决前备份、解决后扫描残留 `<<<<<<<`、批量解决强制确认。
- **失败恢复**：操作日志 + 启动恢复提示，半途中断的写操作先 `cleanup` 而不是盲目重试。
- **任务中心**：统一进度、取消、失败重试；重试不会绕过服务层确认。
- **并发与凭据**：同一工作副本写串行化、跨工作副本并发上限；密码经 stdin、认证失败一次即停、日志脱敏。
- **交付链路**：内置 `svn`/`svnadmin`、干净机器验证、签名/公证拒绝路径测试。
- **产品形态**：免费开源，Windows 端在规划内。

## 8. 建议优先级

**P0：补齐 SVN 日常可用性**

- lock / unlock（二进制资产、设计团队常用）。
- 提交体验：说明复用、失败保留说明与勾选、面板内查看 diff。
- 工作副本过滤 + 更新前远端变更预检。
- 书签连接状态、按主机管理凭据。

**P1：完整客户端与差异化**

- 时间线搜索 + 本地日志缓存。
- 单文件历史 + blame。
- 仓库浏览器：浏览、建目录、复制/移动/删除、tag/branch。
- `svn:externals` 展示与提交。
- 外部 diff 工具集成。
- Finder 扩展、通知、自动刷新。

**P2：平台化**

- Windows 端。
- export/import、switch/relocate、Pristines on Demand。
- 多窗口、书签分组/颜色、工单链接、证书/代理 UI。
