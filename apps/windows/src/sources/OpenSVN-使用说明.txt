OpenSVN Logo｜打开的项目档案夹

设计依据
针对 OpenSVN 管理项目文件的用途，从现有界面中的蓝色文件夹出发重新设计。
打开的文件夹对应 Open 与项目工作副本；两张叠放的文件表达项目内容与版本积累。
正面的主干、分支与三个节点表达版本路径。蓝色高光、纸张折角与克制的投影增加层次。
OpenSVN 字标采用深蓝与项目蓝搭配，字形已转为路径，可独立缩放。

文件
opensvn-icon.svg / .png       标准应用图标，透明背景，PNG 1024 × 1024
opensvn-icon-small.svg / .png 小尺寸专用图标，透明背景，PNG 512 × 512
opensvn-icon-mono.svg / .png  单色标志，透明背景，PNG 1024 × 1024
opensvn-wordmark.svg / .png   独立 OpenSVN 字标，PNG 宽 1600 像素
opensvn-logo.svg / .png       图形与字标的横向组合，PNG 宽 1600 像素
opensvn.ico                   Windows 程序图标
opensvn-presentation.png      1600 × 1420 设计展示图，附首页重绘示意

使用
程序与桌面图标使用 opensvn.ico。
该 ICO 包含 16、24、32、48、64、128、256 像素图层；前三个尺寸使用简化节点的专用图形。
首页、关于页面、README 与网站可以使用横向组合或标准图标。
界面内 16–32 像素位置可直接使用 opensvn-icon-small.svg。
单色图形中的路径与文件之间采用透明留空，可按需要统一改色。
保留图标画布内的留白和阴影空间，避免拉伸或裁切。
